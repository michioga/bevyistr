# 結果表示の操作ガイド

更新日: 2026-09-13

bevyistr（ベビーアイスター）の結果表示は、**結果ファイルを選べば、表示に必要な情報をアプリが案内する**ことを基本方針とします。プリで編集中のモデルと、手動で開く結果の形状は分離します。

この文書は現在の実装を説明します。未実装の機能は末尾に分けて記載しています。

## 結果を開く

**Results → Open Results...** から、表示したい結果ファイルを選びます。

| ファイル | 現在の開き方 |
| --- | --- |
| ASCII VTU | 座標・要素接続・結果をファイルから読み込みます。MSHの事前読み込みは不要です。 |
| 単一ピースPVTU | 参照先のVTUを読み込みます。MSHの事前読み込みは不要です。 |
| FrontISTR ASCII RES | 形状が含まれないため、対応するメッシュを確認して読み込みます。 |

読み込みはバックグラウンドで行われ、Resultsに処理中のメッセージが表示されます。大きな連番結果では時間とメモリを使用します。読み込み中は重複したOpen Results操作を受け付けません。

### VTU／PVTUを開く場合

1. 起動直後でも、そのままResultsへ移動します。
2. Open Results...で、例えば`hinge_vis_psf.0001.pvtu`を選択します。
3. 読み込み完了後、結果の形状にカメラを合わせて表示します。

起動時のデモメッシュや、プリで開いているメッシュへの対応付けは必要ありません。結果ファイル内の形状を使用します。

### RESを開く場合

1. Open Results...で、例えば`hinge.res.0.1`を選択します。
2. 近くにある同名のMSH、または`hecmw_ctrl.dat`から解決したMSHが候補として提示されます。
3. 内容を確認して進めます。

確認ダイアログの操作は次のとおりです。

- **Yes**: 提示されたメッシュと結果を一緒に開きます。
- **No**: 別のMSHを選択します。
- **Cancel**: 開く操作を取り消し、現在の表示を維持します。

ファイル候補がなく、現在の単一メッシュを利用できる場合は、その利用を確認します。候補がなければMSHの選択画面になります。現在の探索は結果フォルダから限定した範囲の親フォルダまでであり、ディスク全体を検索しません。

この操作では、プリの解析設定を置き換えるためにCNTを読み込むのではなく、**結果表示に必要な形状だけ**を読み込みます。RESの節点・要素IDが対応するメッシュを選んでください。IDの一致だけでは、別の解析のメッシュでないことまでは保証できません。

## プリのモデルを保持する

手動で開いた結果は、独立した読み取り専用の形状として保持します。

- **Results**: 結果ファイル側の形状を表示します。
- **Modelなど他のページ**: プリで編集中のモデルに戻ります。
- 再び**Results**へ移動すると、読み込んだ結果を表示します。

結果を開いても、プリの形状・材料・境界条件を上書きしません。結果表示中は、見えていないプリの形状を誤って選択しないようにし、プリ側の選択ハイライトや拘束記号を非表示にします。結果へのホバープローブはまだ未実装です。

読み込みに失敗した場合、新しい結果を部分的に適用せず、直前の結果を保持してエラーを表示します。

## 物理量と変形を選ぶ

- **Choose display field... (項目数)**: Resultsの結果情報の下にあるボタンで、現在のステップに実際に含まれる物理量をポップアップ表示します。節点結果（Node）／要素結果（Element）を区別し、現在の選択には`[x]`が付きます。項目をクリックすると直ちにコンターが切り替わり、ボタン下の**Contour**に選択名を表示します。複数成分は成分ごとに選べ、認識済みのベクトルには大きさの選択もあります。項目が多い場合はスクロールでき、Escで選択を変えずに閉じます。結果未読込時はボタンが無効になります。
- **Deformation: ON/OFF**: 変位による形状変形を切り替えます。コンターの物理量とは独立しています。
- **Deform scale**: 表示上の変形倍率を変更します。解析値やプリの形状は変更しません。

手動で結果を開いた際は、選択したステップに`NodalMISES`があれば初期コンターに使用し、なければそのステップの最初の物理量を使用します。変位がある場合に変形を有効にします。Solveからの自動結果表示は別の経路で、現在は最初のフィールドを初期選択します。

例えば「変形ON＋Mises応力」「変形OFF＋ひずみ」を表示できます。変位の大きさ・成分をコンターとして確認することもできます。

ステップを変えて選択中の物理量が出力されていなかった場合は、勝手に別の物理量へ切り替えません。未出力の値をゼロとして補いません。RESで省略された未使用節点は「結果なし」とし、要素に必要な節点結果の欠落はエラーにします。

## 連番とアニメーション

次のような出力を番号順の系列として検出します。

```text
hinge_vis_psf.0000.pvtu
hinge_vis_psf.0001.pvtu

beam.res.0.0
beam.res.0.5000
beam.res.0.10000

fstrRES/STEP0/conrod.res.0.0
fstrRES/STEP1/conrod.res.0.1
```

- 開いたファイルに対応するステップから表示を始めます。
- **Frame**は読み込んだ系列の表示順で、1から始まります。
- **Step**はファイル側の出力番号です。Frame 2がStep 5000に対応する場合もあります。
- **Time**は結果に記録された時刻です。時刻情報がない場合は現在の実装では0になります。
- Play、前後移動、先頭／末尾への移動で系列を確認できます。
- 再生速度はフレーム毎秒です。物理時刻の差に比例した再生ではありません。
- ワイヤ表示も、変形ON/OFF、倍率変更、フレーム移動に追従します。

FrontISTRのピースVTUを直接選んだ場合は、そのファイルを参照するPVTUが見つかればPVTUの系列を使用します。MPIランク番号は時系列の番号として扱いません。

## Solveで出力する物理量を選ぶ

Solveの **OUTPUT FIELDS** から **RES** または **VTK** のメニューを開きます。それぞれCNTの`!OUTPUT_RES`、`!OUTPUT_VIS`に対応し、独立した設定です。

1. 各項目の **Default／ON／OFF** を選びます。複数項目を続けて選べます。
2. メニュー上部の **Apply output fields** で確定します。Esc、外側のクリック、別ページへの移動は未確定の変更を取り消します。
3. ExportまたはRun FrontISTRで、確定した出力設定をCNTに書き出します。設定はプロジェクトに属し、アプリ共通の`bevyistr.toml`には保存しません。

**DefaultはOFFではありません。** その項目をCNTで指定せず、使用するFrontISTRの既定値に任せます。新規モデルでは構造解析の基本項目としてDISP・NMISESを明示的にONにし、メニューからのOFF指定は行いません。一方、読み込んだCNTのOFFや指定なしは勝手に上書きせず保持します。基本項目がOFFならメニューボタンに注意を表示し、ONへ変更できます。

現在のメニューは、変位・反力、節点／要素の応力・ひずみ・Mises、主応力／主ひずみ、動解析の速度・加速度、シェル回転、接触力などの構造解析用の主要26項目です。ONでも、解析種別・要素・接触状態などにより実際に出力されない場合があります。既存の結果ファイルに後から物理量を追加する機能ではなく、変更を反映するには再解析が必要です。

読み込んだ出力カードの未知の項目名も保持します。GROUP／ACTIONや拡張構文があるカードはメニューで内容を表示するだけにし、編集せず書き戻します。ただし、複数部品を統合するとグループ名が変わるため、名前付き出力GROUPを含むアセンブリの出力は事前検査で停止します。現在はその参照の自動変換に未対応です。

**解析時の出力項目と、Resultsのコンター項目は別です。** Resultsは引き続き実ファイルの配列からメニューを構築し、DISPによる変形ON/OFFはコンター選択と独立して操作します。

## 現在の対応範囲

- VTKは**インラインASCII**、単一ピースPVTU、実装済みのセル型に対応します。
- VTUの節点配列`PointData`と要素配列`CellData`を読み込みます。
- VTK系列は座標・要素接続が固定のものが対象です。変位配列による表示上の変形は利用できます。
- バイナリ／Base64／appended VTK、複数ピースPVTU、系列途中で形状・トポロジーが変わるデータは未対応です。
- 手動RES読み込みは単一メッシュまたは統合済みアセンブリを対象とします。MPIの1ランクだけを完全な結果として扱いません。
- 完全なネイティブMPI結果は、実行したSolveからの結果引き継ぎを利用してください。詳細な解析・未対応形式の確認はParaViewで行います。

## 動作確認チェックリスト

- [ ] 起動直後にhingeのPVTUを開き、MSHを先に開かなくても表示される。
- [ ] conrodのPVTUも、未使用節点数の違いで拒否されず表示される。
- [ ] プリで別のモデルを開いてから結果を開き、Modelへ戻ると元のモデル・設定が保持されている。
- [ ] RESを開くと対応メッシュの候補が提示され、Yes／No／Cancelが説明どおりに動く。
- [ ] コンターの切り替えと変形ON/OFFを独立して操作できる。
- [ ] 変形倍率を変更してもワイヤが元の形状に残らない。
- [ ] 連番をPlayで再生でき、Frame／Step／Timeが変化する。
- [ ] 不正な結果を開いた場合、直前の結果やプリのモデルが失われない。
- [ ] SolveでRESのREACTIONをON、VTKのREACTIONをOFFにしてApplyすると、Export先CNTで別々の指定になる。
- [ ] メニュー内で変更してEscで閉じると、元の設定のままになる。Apply後はCtrl+Zで戻せる。
- [ ] 出力済みプロジェクトをOpen Projectで開き直すと、各出力項目の指定が復元される。

自動テストでは、VTKからの独立した形状読み込み、節点／要素配列、RESとVTKの値の照合、連番検出、プリモデル保持、読み込み失敗時の状態保持などを確認しています。実画面の操作感は上記のチェックリストで確認します。

## 設計方針・今後の課題（未実装）

- 熱・流体などの解析種別に応じた出力項目の編集、出力頻度の編集、名前付き出力GROUPのアセンブリへの参照変換。
- ソルバー選択などへのポップアップUIの展開。以前提供された`bevy_menu.zip`を参考にします。
- 複数ピースPVTUの区画・ゴースト処理、バイナリVTKへの対応。
- 結果のホバープローブ、選択節点の時系列グラフ、クリッピングなどの便利機能。

「操作は直観的に、数値と対応関係の確認は厳密に」という方針を維持します。
