## 0.3.0向け：履歴CSV保存

2026-09-21、Windowsの`feat/probe-history-csv`作業ツリーで
`cargo test --workspace --locked --offline -j 1`を実行し、339成功・0失敗・6スキップを確認しました。
CSV／履歴関連は11テスト（今回追加6件を含む）です。対象はグラフとCSVの共通抽出、
スナップショット、特殊文字、欠損、原子的な保存、UIの有効／無効と完了通知、実クリック経路です。
保存ダイアログは自動テストでは代替処理を使用しており、下記の実機確認は別途必要です。

- [ ] 円柱などの結果を固定し、HISTORY直下のExport pinned history CSV...から保存できる。Savedに対象と保存先が出る。
- [ ] CSVの部品・節点／要素ID、全Frame／Step／Time、値がPINNED／HISTORYと一致する。部品間の同一IDを混同しない。
- [ ] 変形倍率や色範囲の変更で保存値が変わらない。欠損・非有限値は空欄とunavailableになり、0に変わらない。
- [ ] 保存ダイアログのキャンセル、上書き確認のキャンセルで既存ファイルが変わらない。失敗時は理由が表示される。
- [ ] 保存中の二重起動を防ぎ、処理が終了すると再び保存できる。対象なしの場合は保存不可と理由が分かる。
- [ ] 保存操作中に表示フィールド・フレーム・結果を変更しても、CSVは開始時の対象・全フレームを保持する。
- [ ] Windows／Linuxで保存ダイアログ・上書き確認・完了表示を確認する。自動テスト成功だけで実機確認済みにしない。

- [ ] 一定値フィールドでは説明と単色凡例が出て、値の変化するフィールドへ切り替えるとグラデーションに戻る。
