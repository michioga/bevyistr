# 動作確認チェックリスト

- [ ] 起動直後にhingeのPVTUを開き、MSHを先に開かなくても表示される。
- [ ] conrodのPVTUも、未使用節点数の違いで拒否されず表示される。
- [ ] cavity_flowのPVTUで8ピースの注意が表示され、PRESSURE／VELOCITYを切り替えられる。プリモデルは保持される。
- [ ] プリで別のモデルを開いてから結果を開き、Modelへ戻ると元のモデル・設定が保持されている。
- [ ] RESを開くと対応メッシュの候補が提示され、Yes／No／Cancelが説明どおりに動く。
- [ ] コンターの切り替えと変形ON/OFFを独立して操作できる。
- [ ] 一定値フィールドでは説明と単色凡例が出て、値の変化するフィールドへ切り替えるとグラデーションに戻る。
- [ ] 結果・ソルバー・出力項目の右端の`>`／`v`が開閉に追従し、ホバーで枠と操作ヒントが表示される。
- [ ] VELOCITYの大きさ／成分を続けて選択しても、Open Resultsのファイルダイアログが開かない。Open Results自体をクリックすると通常どおり開く。
- [ ] 変形倍率を変更してもワイヤが元の形状に残らない。
- [ ] 再生停止中に表面をホバーすると値とマーカーが出て、節点／要素フィールドの違いが分かる。変形倍率を変えても解析値は変わらない。
- [ ] 再生開始、カメラのドラッグ、UI上への移動でホバープローブが消える。
- [ ] 停止中の結果表面をクリックするとPINNED欄に対象が固定され、マウスを離してフレームを進めても同じ部品の同じ節点／要素の値が更新される。
- [ ] Clear pinned probeで解除できる。ドラッグやUI操作では固定対象が変わらない。新しい結果を開く／Modelへ移動すると解除される。
- [ ] 固定対象が節点のときに要素フィールドへ切り替える（または逆）と、値を変換せずunavailableと表示する。
- [ ] 連番をPlayで再生でき、Frame／Step／Timeが変化する。
- [ ] `<`／`>`で全フレームを1コマずつ移動でき、`|<`／`>|`は先頭／末尾へ移動する。再生中に移動ボタンを押すと停止し、ファイルのStep番号が飛んでいても読み込んだ順で移動する。
- [ ] All framesでは再生中も凡例の範囲が固定され、Current frameに戻すと現在フレームの範囲に戻る。物理量の変更と変形ON/OFFは独立して動作する。
- [ ] 不正な結果を開いた場合、直前の結果やプリのモデルが失われない。
- [ ] SolveでRESのREACTIONをON、VTKのREACTIONをOFFにしてApplyすると、Export先CNTで別々の指定になる。
- [ ] メニュー内で変更してEscで閉じると、元の設定のままになる。Apply後はCtrl+Zで戻せる。
- [ ] 結果／出力項目メニューで↑↓・Home／Endの移動先が見え、Enterで選択できる。出力項目でEnterによる変更後にEscを押しても解析設定には反映されない。
- [ ] 出力済みプロジェクトをOpen Projectで開き直すと、各出力項目の指定が復元される。

自動テストでは、VTKからの独立した形状読み込み、節点／要素配列、RESとVTKの値の照合、連番検出、プリモデル保持、読み込み失敗時の状態保持などを確認しています。複数ピースについては、値を平均しないこと、共通色範囲、2フレームの系列、ゴースト除外、欠落・不一致時の拒否を確認します。実データの8ピース読み込みテストも用意しています。実画面の操作感は上記のチェックリストで確認します。

このチェックリストは開発者向けです。未チェック項目を動作確認済みとみなさず、確認時にはブランチ・コミット・データ名・実行環境も記録します。
