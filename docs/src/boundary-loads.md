# BC / Loads：拘束と荷重

## 基本手順

1. 対象の節点・面を選択します。
2. 拘束、節点荷重、圧力、重力などの種類を選びます。
3. 対象数、自由度、方向、値を数値欄で確認します。
4. プレビューを確認して**Apply**で確定します。

矢印や回転記号は対象・向きの確認用です。解析入力の値は数値欄を基準にしてください。並進／回転の自由度と、力／モーメントを混同しないようにします。

圧力は対象面、重力は加速度と方向を確認します。回転の設定では直接の自由度指定か中心節点を基準とする指定かも確認してください。

モデル、材料定数、荷重の単位系は整合させる必要があります。アプリは既存メッシュの単位を推測して変換しません。

解析設定の変更はCtrl＋Z／Ctrl＋Yで取り消し・やり直しできます。細かな条件別の操作例と撮影素材は今後追加します。
