# 0.3.0 リリースノート（公開準備中）

2026-10-25時点の公開候補です。crates.ioへの公開・Windows ZIPの配布はまだ完了していません。
以下は0.2.0からの変更点です。アプリの版番号表示だけでは公開済みとは判断しないでください。

## 結果の確認と比較

- 固定した節点または要素の全フレーム履歴をCSV保存できます。欠損値はゼロにせず、状態を記録します。
- 同じ物理量について最大4対象を比較できます。色・対象ID・共通軸の履歴を表示します。
  CSV保存は現在の固定対象だけで、比較一覧全体の一括保存ではありません。
- RES/VTU/PVTUの固有値メタデータを保持し、ModeとEigenvalueを表示します。
  モード順と元番号を区別し、物理時間・周波数・往復振動を推測しません。
- シークバーに現在位置/総数を表示します。通常結果はFrame、固有値系列はMode (order)です。
  ドラッグや前後移動で再生を停止し、左右キーでも1コマずつ移動できます。
- 比較の状態、CSVの保存対象、再生速度が物理時間ではないことの案内を強化しました。

操作は[プローブ・比較・CSV](results/probe.md)と[連番表示](results/animation.md)を参照してください。

## 解析設定の安全性と操作

- 読み込んだCNTに保持できない設定がある場合、理由を示してExport/Runを停止します。
  設定を黙って省略した別の解析として実行しません。既存結果の閲覧は可能です。
- 線形反復と非線形反復の数値を分離し、解析タイプ・ソルバーの選択をポップアップに統一しました。
  非線形STEP編集は対応する単一・固定増分等の範囲に限ります。
- 固有値解析のモード数、許容差、最大反復、シフトを専用欄から編集できます。
- RES/VTKの保存ON/OFFと保存間隔を独立して設定できます。間隔の単位はソルバーステップです。
  固有値解析では全モード出力のため間隔欄は編集できません。
- RESを保存しない実行では、以前のRESを今回の結果として自動読込しません。
  VTKだけ出力した場合はOpen Resultsから開いてください。

詳細は[Solve](solve/index.md)、[固有値設定](solve/eigen.md)、[保存する結果](solve/output-fields.md)を参照してください。

## 0.2.0から利用する際の注意

元の解析入力はバックアップしてください。0.2.0で開けた入力でも、保持できない設定がある場合は
新しい検査によりExport/Runが停止することがあります。警告を消すために重要な設定を削除しないでください。
FrontISTR/MPI/Gmshは同梱しません。既存結果の閲覧だけならソルバーは不要です。

## 既知の制限・今回含めないもの

- FrontISTR全キーワードの編集、複数STEPや高度な非線形設定の完全な再出力は対象外です。
- VTKのbinary/appendedエンコード、トポロジーが変わる系列、分割ピースの完全な統合は対象外です。
- 比較全体CSV、グラフ拡大、パネル折りたたみ、SolidCraft風カメラ操作は未実装です。
- 流体例題はFrontISTRサポートへ問い合わせ中です。解析成功の保証や検証完了とは扱いません。
- LinuxのCI検証とLinux GUIの実機動作確認は別です。

入力・結果の詳細な対応範囲は[対応範囲](limitations.md)と[結果形式の制限](results/limitations.md)を参照してください。
