# 困ったとき

## Setup incomplete／CNT re-export blockedが表示される

元CNTにbevyistrが再出力時に保持できない記述があるため、Export／Runを止めています。
件数は変換できない記述の数です。Solveでファイル名・行番号・理由を確認できます。
保存済みの結果をOpen Resultsで閲覧することは可能です。

例えば公式例題のconrodでは、前処理の`PRECOND=3`、BOUNDARYの`GRPID`省略書式、
FrontISTR側の描画・可視化出力設定が該当します。元の解析入力の不備や解析失敗を示す
件数ではありません。[設定保持の制限](solve/index.md)を確認し、再解析には元入力を保管してください。

## コンターが単色になる

選択した物理量のMin／MaxとConstant field表示を確認します。一定値なら単色は正常です。例えば流体の初期フレームでは、一部の速度成分や圧力がすべて0の場合があります。[コンター・色範囲](results/contours.md)を参照してください。

## アニメーションにならない

Frameの総数を確認します。1フレームだけでは時間変化を再生できません。PVTUのランク別VTUは時間ステップではありません。[連番](results/animation.md)を参照してください。

## RESを開くとメッシュを尋ねられる

RESに形状が含まれないためです。結果と対応するMSHを選びます。無関係なメッシュを節点数だけで対応付けないでください。

## 部品境界の内側にも線・面が見える

複数ピースPVTUでは、区画を独立して保持します。重複指定のないセルや内部の分割境界は残ります。[複数ピースの制限](results/opening.md)を確認してください。

## ソルバーが起動しない

Solveの状態・内部ログ・実行ファイル・MPIランタイムを確認します。実行方式と線形ソルバーの種類は別の設定です。

次期版では、起動前に入力の準備・検査で止まった場合は`Status: Blocked`と`Not started`を表示します。
公開済み0.3.0では、この場合も`Failed`と表示されます。`Preflight`や`Setup compatibility`の詳細が
出ている場合、FrontISTRの解析が失敗したという意味ではありません。
`CNT re-export blocked`の場合は、bevyistrが元設定を保持して再出力できないための停止です。
元入力は保管し、保存済みの解析結果はOpen Resultsから閲覧できます。

問題を報告するときは、アプリのブランチ／コミット、OS、操作手順、エラーメッセージ、公開可能な最小データを添えてください。利用許可のない解析データや個人情報は共有しないでください。
