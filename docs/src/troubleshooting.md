# 困ったとき

## コンターが単色になる

選択した物理量のMin／MaxとConstant field表示を確認します。一定値なら単色は正常です。例えば流体の初期フレームでは、一部の速度成分や圧力がすべて0の場合があります。[コンター・色範囲](results/contours.md)を参照してください。

## アニメーションにならない

Frameの総数を確認します。1フレームだけでは時間変化を再生できません。PVTUのランク別VTUは時間ステップではありません。[連番](results/animation.md)を参照してください。

## RESを開くとメッシュを尋ねられる

RESに形状が含まれないためです。結果と対応するMSHを選びます。無関係なメッシュを節点数だけで対応付けないでください。

## 部品境界の内側にも線・面が見える

複数ピースPVTUでは、区画を独立して保持します。重複指定のないセルや内部の分割境界は残ります。[複数ピースの制限](results/opening.md)を確認してください。

## ソルバーが起動しない

Solveの状態・内部ログ・実行ファイル・MPIランタイムを確認します。実行方式と線形ソルバーの種類は別の設定です。

問題を報告するときは、アプリのブランチ／コミット、OS、操作手順、エラーメッセージ、公開可能な最小データを添えてください。利用許可のない解析データや個人情報は共有しないでください。
