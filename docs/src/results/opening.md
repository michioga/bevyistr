# 結果を開く

**Results → Open Results...** から、表示したい結果ファイルを選びます。

ファイルダイアログはOpen Resultsボタンのクリック確定、またはそのボタンにフォーカスを合わせてEnter／Spaceを押した時だけ開きます。コンターフィールドの選択やメニューの開閉は、新しいファイルを開く操作ではありません。

| ファイル | 現在の開き方 |
| --- | --- |
| ASCII VTU | 座標・要素接続・結果をファイルから読み込みます。MSHの事前読み込みは不要です。 |
| PVTU（単一／複数ピース） | 参照先のASCII VTUをすべて読み込みます。MSHの事前読み込みは不要です。 |
| FrontISTR ASCII RES | 形状が含まれないため、対応するメッシュを確認して読み込みます。 |

読み込みはバックグラウンドで行われ、Resultsに処理中のメッセージが表示されます。大きな連番結果では時間とメモリを使用します。読み込み中は重複したOpen Results操作を受け付けません。

## VTU／PVTUを開く場合

1. 起動直後でも、そのままResultsへ移動します。
2. Open Results...で、例えば`hinge_vis_psf.0001.pvtu`を選択します。
3. 読み込み完了後、結果の形状にカメラを合わせて表示します。

起動時のデモメッシュや、プリで開いているメッシュへの対応付けは必要ありません。結果ファイル内の形状を使用します。

## 複数ピースPVTU

PVTUを選ぶと、参照される全ピースの形状・結果を読み込みます。各ピースの値は独立して保持し、全ピース共通のコンター範囲を使用します。現在フレーム／全フレームの範囲は[COLOR RANGE](contours.md)で選べます。座標が一致していても節点を結合したり、異なる値を平均したりしません。プローブのIDはピース内のローカルIDなので、部品番号と組み合わせて確認してください。

**これは区画を保持した表示であり、グローバル所有情報を復元した一体メッシュではありません。** 重複指定のないセルや内部の分割境界は残ります。特にWire／X-rayではそれらが見える場合があり、Resultsにも注意を表示します。

`vtkGhostType`がある場合、セルのduplicate（1）／hidden（32）を除外します。節点のduplicate（1）は所有セルからも参照されるため保持し、hidden（2）を参照するセルは除外します。除外後の不要節点と対応する配列値も除き、残すID・値は変更しません。その他のフラグは推測せずエラーにし、このメタデータ自体はコンター項目にしません。フラグの意味は[VTKの定義](https://vtk.org/doc/nightly/release/9.6/html/classvtkDataSetAttributes.html)に従います。

同じフレームの各ピースには同じフィールド構成と時刻が必要です。系列の途中でピース数・順序・形状・接続が変化するもの（ゴースト除外による変化も含む）は未対応です。参照先の欠落、重複参照、不一致があれば読み込み全体を中止し、直前の結果を維持します。

確認用の例はFrontISTRチュートリアル内の`18_cavity_flow/cavityflow_vis_psf.0000.pvtu`です。手元のデータは8ピース・1フレームなので、この例だけではアニメーションにはなりません。PRESSUREやVELOCITYの大きさ／成分をメニューで選択できます。流速は変位ではなく、Deformationによる形状変形には使用しません。

## RESを開く場合

1. Open Results...で、例えば`hinge.res.0.1`を選択します。
2. 近くにある同名のMSH、または`hecmw_ctrl.dat`から解決したMSHが候補として提示されます。
3. 内容を確認して進めます。

確認ダイアログの操作は次のとおりです。

- **Yes**: 提示されたメッシュと結果を一緒に開きます。
- **No**: 別のMSHを選択します。
- **Cancel**: 開く操作を取り消し、現在の表示を維持します。

ファイル候補がなく、現在の単一メッシュを利用できる場合は、その利用を確認します。候補がなければMSHの選択画面になります。現在の探索は結果フォルダから限定した範囲の親フォルダまでであり、ディスク全体を検索しません。

この操作では、プリの解析設定を置き換えるためにCNTを読み込むのではなく、**結果表示に必要な形状だけ**を読み込みます。RESの節点・要素IDが対応するメッシュを選んでください。IDの一致だけでは、別の解析のメッシュでないことまでは保証できません。

## プリのモデルを保持する

手動で開いた結果は、独立した読み取り専用の形状として保持します。

- **Results**: 結果ファイル側の形状を表示します。
- **Modelなど他のページ**: プリで編集中のモデルに戻ります。
- 再び**Results**へ移動すると、読み込んだ結果を表示します。

結果を開いても、プリの形状・材料・境界条件を上書きしません。結果表示中は、見えていないプリの形状を誤って選択しないようにし、プリ側の選択ハイライトや拘束記号を非表示にします。結果の値は[ホバープローブ](probe.md)で確認できます。

読み込みに失敗した場合、新しい結果を部分的に適用せず、直前の結果を保持してエラーを表示します。
