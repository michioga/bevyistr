# 現在の対応範囲

- VTKは**インラインASCII**、単一／複数ピースPVTU、実装済みのセル型に対応します。複数ピースは[区画を保持して表示](opening.md)します。
- VTUの節点配列`PointData`と要素配列`CellData`を読み込みます。
- VTK系列は座標・要素接続が固定のものが対象です。変位配列による表示上の変形は利用できます。
- バイナリ／Base64／appended VTK、系列途中で形状・トポロジーが変わるデータは未対応です。
- 手動RES読み込みは単一メッシュまたは統合済みアセンブリを対象とします。MPIの1ランクだけを完全な結果として扱いません。
- 完全なネイティブMPI結果は、実行したSolveからの結果引き継ぎを利用してください。詳細な解析・未対応形式の確認はParaViewで行います。
- 固有値解析の変位ベクトル・各成分は読めますが、RESのグローバルデータ／VTKの`FieldData`にある`EIGENVALUE`の数値表示は未対応です。モード番号を時刻や周波数に読み替えません。
