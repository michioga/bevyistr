# Results：結果表示の入口

結果ファイルを開き、物理量を選択してコンターを表示します。解析設定のモデルと、手動で開いた結果の形状は分離して保持します。

1. [結果を開く](opening.md)：VTU／PVTUはそのまま、RESは対応メッシュと一緒に開きます。
2. [コンター・変形・色範囲](contours.md)：Display fieldで物理量を選び、変形表示を独立に切り替えます。
3. [ホバープローブ](probe.md)：停止中に表面の節点・要素値を確認します。
4. [連番とアニメーション](animation.md)：フレームを移動し、全フレーム共通の色範囲で比較します。

最小値と最大値がともに0の場合は、コンターが単色になることがあります。表示失敗と区別するため、Constant fieldの表示と元の結果値を確認してください。

未対応の結果形式は[対応範囲](limitations.md)に記載します。
