# 物理量と変形を選ぶ

- **Display field: 現在値**: Resultsの結果情報の下にあるボタンで、現在のステップに実際に含まれる物理量をポップアップ表示します。節点結果（Node）／要素結果（Element）を区別し、現在の選択には`[x]`が付きます。項目をクリックすると直ちにコンターが切り替わり、ボタン内に選択名、下に項目数を表示します。複数成分は成分ごとに選べ、認識済みのベクトルには大きさの選択もあります。項目が多い場合はスクロールでき、Escで選択を変えずに閉じます。結果未読込時はボタンが無効になります。
- **COLOR RANGE**: `Current frame`（既定）は現在フレームの範囲、`All frames`は読み込んだ全フレームで共通の範囲を使用します。どちらも複数ピースに共通の色範囲です。All framesではアニメーション中も「同じ色＝同じ値」になり、物理量を変えるとその物理量の範囲へ切り替わります。未出力フレームは集計せず、0で補いません。凡例にも範囲のモードを表示します。元の解析値・変形倍率は変更しません。
- **Deformation: ON/OFF**: 変位による形状変形を切り替えます。コンターの物理量とは独立しています。
- **Deform scale**: 表示上の変形倍率を変更します。解析値やプリの形状は変更しません。

メニューを開くボタンには右端に独立した`>`を表示し、開いている間は`v`になります。ホバーまたはキーボードフォーカス時には枠を明るくし、操作ヒントを表示します。結果フィールド、解析方式、ソルバー、RES／VTK出力項目で共通の表示です。

現在フレームのフィールドの有限な最小値・最大値が等しい場合は、**Constant field: 値 (uniform color)**と表示します。これは色の変化がない一定値であり、表示失敗ではありません。凡例の対象範囲も一定ならモデルと同じ単色になり、値は一度だけ表示します。All framesで他フレームに異なる値があれば、現在フレームが一定値でも凡例は全フレームのグラデーションを維持します。上部のMin／Maxは引き続き現在フレームの解析値であり、凡例の全フレーム範囲とは区別します。ベクトルの場合は大きさの一定値を指します。欠損値だけのフィールドや空配列は一定値0とは扱いません。例えば手元のcavity_flowの時刻0では`VELOCITY[2]`は全て0ですが、`VELOCITY[1]`には0〜0.001の範囲があります。

手動で結果を開いた際は、選択したステップに`NodalMISES`があれば初期コンターに使用し、なければそのステップの最初の物理量を使用します。変位がある場合に変形を有効にします。Solveからの自動結果表示は別の経路で、現在は最初のフィールドを初期選択します。

例えば「変形ON＋Mises応力」「変形OFF＋ひずみ」を表示できます。変位の大きさ・成分をコンターとして確認することもできます。

ステップを変えて選択中の物理量が出力されていなかった場合は、勝手に別の物理量へ切り替えません。未出力の値をゼロとして補いません。RESで省略された未使用節点は「結果なし」とし、要素に必要な節点結果の欠落はエラーにします。

結果フィールド・出力項目・解析方式・ソルバーのポップアップは共通のキー操作に対応します。↑／↓で移動、Home／Endで先頭／末尾の選択可能な項目へ移動し、Enterで実行、Escで変更せず閉じます。フォーカス中の項目を色で示し、画面外にある場合はポップアップ内をスクロールします。出力項目メニューではEnterで項目を変更しても下書きのままで、**Home → Enter**で上部のApplyを実行して確定します。Escは下書きを破棄します。

> 画面・動画は準備中です。メニューの右端の`>`を押して開き、項目名を選択します。色の時間比較にはCOLOR RANGEのAll framesを選びます。
