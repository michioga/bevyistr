# はじめに

**bevyistr**は、FrontISTRの解析準備と結果表示を行うプリポストです。読み方は**Bevy Aistar（ベビーアイスター）**です。

> 操作はビューポートで直観的に、数値と対応関係の確認は厳密に。

本書は日本語の操作マニュアルです。画面内のボタン名は実際の英語表記を使用します。アプリは開発中であり、未実装の機能と制限は[対応範囲](limitations.md)に分けて記載します。

**v0.2.0はcrates.ioで公開済みです。** インストール方法は[起動と最初の操作](getting-started.md)を参照してください。

## 目的から読む

- 初めて使う：[起動と最初の操作](getting-started.md)
- 既存プロジェクトを確認する：[Model](model.md)
- 材料を割り当てる：[Materials](materials.md)
- 解析を実行する：[Solve](solve/index.md)
- 結果ファイルを表示する：[Results](results/index.md)

FrontISTRのキーワード・要素・理論の原本は[公式資料](references.md)です。本書はbevyistrの操作と対応範囲を説明し、ソルバーの仕様書を置き換えるものではありません。

スクリーンショット・動画は順次追加します。画像がなくても手順を追えるよう、対象ファイル、操作、確認結果を本文に記載します。

本書はリポジトリの当該コミットに対応します。アプリのバージョン更新はmainへのマージ時に行い、ドキュメント整備だけでバージョンは変更しません。
