# 画面・カメラ・選択

左側のページ切り替えでModel、Contact、BC / Loads、Materials、Solve、Resultsへ移動します。共通のVIEWから表示方式や部品色／材料色を切り替えられます。

## カメラ

| 操作 | 動作 |
| --- | --- |
| 中ボタンドラッグ | 回転 |
| Shift＋中ボタンドラッグ | 平行移動 |
| ホイール | 拡大・縮小 |
| F | 対象にフォーカス |
| 右上のビューキューブ | 面・辺・頂点の向きへ切り替え |

横ドラッグは画面の縦方向を軸に、縦ドラッグは画面の横方向を軸に回転します。モデルの底面を画面下側に置いた状態で側面を正面に向けるには、横にドラッグします。

### タッチパッド

左側の **VIEW** で **Touchpad (Alt)** または **Touchpad (Space)** を選びます。
AltはBlenderの3ボタンマウスエミュレートと同じ開始操作です。OSがAltドラッグをウィンドウ操作に使う場合はSpaceを選びます。
中ボタンを使う設定へ切り替えるには **Mouse** を選びます。選んだ設定は `bevyistr.toml` に保存されます。

| 動作 | Touchpad (Alt) | Touchpad (Space) |
| --- | --- | --- |
| 回転 | Alt＋左ドラッグ | Space＋左ドラッグ |
| 平行移動 | Alt＋Shift＋左ドラッグ | Space＋Shift＋左ドラッグ |
| 拡大・縮小 | Alt＋Ctrl＋左上下ドラッグ | Space＋Ctrl＋左上下ドラッグ |

修飾キーを押してからビューポート上でドラッグを始めます。ズームは下へドラッグすると拡大します。
タッチパッドがホイールとして送るスクロールもズームに使えます。
Touchpad (Alt) で選択対象を除外するにはCtrl＋Shiftを使います。

## 選択

まずNode／Edge／Face／Elementで対象を選びます。利用可能な対象はページの作業によって異なります。

| 操作 | 動作 |
| --- | --- |
| クリック／ドラッグ | 選択を置き換え |
| Ctrl＋クリック／ドラッグ | 追加 |
| Shift＋クリック／ドラッグ | 選択・非選択を反転 |
| AltまたはCtrl＋Shift | 選択から除外 |
| 左から右へドラッグ | 枠内に完全に含まれる対象 |
| 右から左へドラッグ | 枠に交差・接触する対象 |
| ダブルクリック | 接続した境界へ拡張 |
| トリプルクリック | 接続した成分へ拡張 |

Single／Coplanar／Smoothは対応する対象の選択拡張に使用します。Faceは面、ElementはFEM要素そのものです。例えばソリッドでは表面の面を選ぶことと、その背後の体積要素を選ぶことは異なります。Edgeでは連続した特徴線をたどります。ページ内の**Selection guide**とホバープレビューを確認してください。

## 数値とメニュー

移動・回転などの厳密な値は、表示される数値欄に入力してEnterで確定します。数値編集ではEscで未確定の変更を取り消します。

右端に`>`があるボタンは選択メニューです。開くと`v`に変わります。↑／↓、Home／End、Enter、Escにも対応します。出力項目のメニューだけは下書きを**Apply**でまとめて確定します。
