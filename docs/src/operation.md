# 画面・カメラ・選択

左側のページ切り替えでModel、Contact、BC / Loads、Materials、Solve、Resultsへ移動します。共通のVIEWから表示方式や部品色／材料色を切り替えられます。

## カメラ

| 操作 | 動作 |
| --- | --- |
| 中ボタンドラッグ | 回転 |
| Shift＋中ボタンドラッグ | 平行移動 |
| ホイール | 拡大・縮小 |
| F | 対象にフォーカス |
| 右上のビューキューブ | 面・辺・頂点の向きへ切り替え |

## 選択

まずNode／Edge／Face／Elementで対象を選びます。利用可能な対象はページの作業によって異なります。

| 操作 | 動作 |
| --- | --- |
| クリック／ドラッグ | 選択を置き換え |
| Ctrl＋クリック／ドラッグ | 追加 |
| Shift＋クリック／ドラッグ | 選択・非選択を反転 |
| AltまたはCtrl＋Shift | 選択から除外 |
| 左から右へドラッグ | 枠内に完全に含まれる対象 |
| 右から左へドラッグ | 枠に交差・接触する対象 |
| ダブルクリック | 接続した境界へ拡張 |
| トリプルクリック | 接続した成分へ拡張 |

Single／Coplanar／Smoothは対応する対象の選択拡張に使用します。Faceは面、ElementはFEM要素そのものです。例えばソリッドでは表面の面を選ぶことと、その背後の体積要素を選ぶことは異なります。Edgeでは連続した特徴線をたどります。ページ内の**Selection guide**とホバープレビューを確認してください。

## 数値とメニュー

移動・回転などの厳密な値は、表示される数値欄に入力してEnterで確定します。数値編集ではEscで未確定の変更を取り消します。

右端に`>`があるボタンは選択メニューです。開くと`v`に変わります。↑／↓、Home／End、Enter、Escにも対応します。出力項目のメニューだけは下書きを**Apply**でまとめて確定します。
