# 対応範囲と今後の予定

本マニュアルは公開済み0.3.0に対応します。FrontISTRの全機能が編集可能という意味ではありません。

- [結果ファイルの対応範囲](results/limitations.md)
- インラインASCIIの結果表示を対象とし、未対応形式はエラーとして扱います。
- CNT／MSHの未知の設定は、すべてがUIで編集・保持できるとは限りません。既存プロジェクトを書き出す際は、元データを保存して差分を確認してください。
- `!OUTPUT_RES`／`!OUTPUT_VIS`のGROUP／ACTIONを含む拡張カードは単体では編集せず保持します。
  名前付き出力GROUPを含む複数部品の統合出力は、参照を自動変換できないため停止します。
  詳細は[Solveの出力設定](solve/output-fields.md)を参照してください。
- 大規模モデルで快適に操作できる節点数の保証値はありません。読込・選択・コンター・
  プローブの負荷は要素型、表面数、結果系列、区画数、実行環境で異なります。

## 設計方針・今後の課題（未実装）

- 熱・流体などの解析種別に応じた出力項目の編集、名前付き出力GROUPのアセンブリへの参照変換。
  RES／VTKの保存間隔の編集は0.3.0で対応済みです。
- その他の選択操作へのポップアップUIの展開（結果フィールド・出力項目・解析方式・ソルバーは対応済み）。
- グローバルID・所有情報によるPVTU区画統合、未指定重複の適切な処理、より広いゴースト形式、バイナリVTKへの対応。
- クリッピング、比較対象全体の一括CSV保存、履歴グラフの拡大操作（単一履歴CSV保存と最大4対象の同一物理量の比較は0.3.0に追加）。

「操作は直観的に、数値と対応関係の確認は厳密に」という方針を維持します。
