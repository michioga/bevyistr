# Solveで出力する物理量を選ぶ

Solveの解析方式は **Analysis type: ...**、連立方程式ソルバーは **Linear solver: ...** のポップアップから選べます。MUMPSは先頭に表示しますが、メニューを開くだけでは現在値を変更しません。選択中の項目は`[x]`で示し、項目をクリックすると確定します。矢印キー／Enterでも選択でき、Escや外側へのフォーカス移動では変更せず閉じます。Ctrl+Z／Ctrl+Yで取消・やり直しができます。数値欄は独立して保持します。ソルバーのDirectと、下部の実行方式Direct／MPIは別の設定です。

Solveの **OUTPUT FIELDS** から **RES** または **VTK** のメニューを開きます。それぞれCNTの`!OUTPUT_RES`、`!OUTPUT_VIS`に対応し、独立した設定です。

1. 各項目の **Default／ON／OFF** を選びます。複数項目を続けて選べます。
2. メニュー上部の **Apply output fields** で確定します。Esc、外側のクリック、別ページへの移動は未確定の変更を取り消します。
3. ExportまたはRun FrontISTRで、確定した出力設定をCNTに書き出します。設定はプロジェクトに属し、アプリ共通の`bevyistr.toml`には保存しません。

**DefaultはOFFではありません。** その項目をCNTで指定せず、使用するFrontISTRの既定値に任せます。新規モデルでは構造解析の基本項目としてDISP・NMISESを明示的にONにし、メニューからのOFF指定は行いません。一方、読み込んだCNTのOFFや指定なしは勝手に上書きせず保持します。基本項目がOFFならメニューボタンに注意を表示し、ONへ変更できます。

現在のメニューは、変位・反力、節点／要素の応力・ひずみ・Mises、主応力／主ひずみ、動解析の速度・加速度、シェル回転、接触力などの構造解析用の主要26項目です。ONでも、解析種別・要素・接触状態などにより実際に出力されない場合があります。既存の結果ファイルに後から物理量を追加する機能ではなく、変更を反映するには再解析が必要です。

読み込んだ出力カードの未知の項目名も保持します。GROUP／ACTIONや拡張構文があるカードはメニューで内容を表示するだけにし、編集せず書き戻します。ただし、複数部品を統合するとグループ名が変わるため、名前付き出力GROUPを含むアセンブリの出力は事前検査で停止します。現在はその参照の自動変換に未対応です。

**解析時の出力項目と、Resultsのコンター項目は別です。** Resultsは引き続き実ファイルの配列からメニューを構築し、DISPによる変形ON/OFFはコンター選択と独立して操作します。
