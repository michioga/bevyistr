# 固有値解析の設定（0.3.0）

Solveで **Analysis type → Eigenvalue** を選ぶと、**EIGENVALUE | !EIGEN (Lanczos)** 欄が表示されます。
この機能は公開済みv0.2.0には含まれません。

| 画面の項目 | CNTの項目 | bevyistrの初期値 |
| --- | --- | --- |
| Requested modes | NGET：求める固有値数 | 3 |
| Tolerance | LCZTOL：固有値解析の許容差 | 1e-6 |
| Max iterations | LCZMAX：最大反復数 | 60 |
| Shift (sigma) | SIGMA：シフト量 | 0.01 |

モード数3は従来のbevyistr出力を引き継いだ初期値です。他の3項目は
[FrontISTRの!EIGEN仕様](https://source-docs.frontistr.com/keyword_reference/cnt/eigen.html)の既定値に対応します。

1. 各欄に数値を入力し、Enterで確定します。Escは編集前の値へ戻します。
2. 最大反復数にはモード数より十分大きな値を指定してください。bevyistrは少なくとも「最大反復数 > モード数」を要求し、満たさない場合はExport／Runの事前検査で停止します。十分な収束を保証する条件ではありません。
3. 許容差は有限の正数、シフト量は有限値です。シフト量のゼロ・負値も入力できますが、解析に適する値はモデルに応じて判断してください。周波数Hzへの換算は行いません。
4. ExportしたCNTは、例えば次の形になります。

```text
!SOLUTION, TYPE=EIGEN
!EIGEN
5, 1.0000000000000000e-8, 80, 1.0000000000000000e-2
```

線形ソルバーのNITER／RESID、非線形のMAXITER／CONVERGとは別の設定です。
MUMPSを選んでも固有値設定は表示されます。解析タイプを変更すると専用欄は隠れますが、入力値は保持されます。
Ctrl+Z／Ctrl+YによるUndo／Redoも他の解析設定と同様です。

## 読み込みと精度

!EIGENの1行を読み込み、許容差・シフト量はf64で保持します。
出力は17桁の有効数字を使い、画面表示の丸めやf32変換で再出力値を変えません。
NGETのみの行、末尾の省略、途中の空欄は、該当するオプション項目の既定値として読み込みます。
Fortran形式のD指数も読み込めます。

追加パラメータ・余分な列や行・繰り返しの!EIGEN・非数値／非有限値・不正な範囲は、
未対応／不正として通知し、再出力を止めます。EIGEN解析で!EIGENカード自体が欠ける場合も、
ソルバーの暗黙値を勝手に変更しないため停止します。STATICEIGENは今回の対応範囲に含めません。
他のキーワードに未対応設定があるCNTは、固有値欄を編集できても引き続き出力制限が残ります。

これは解析入力の設定です。Resultsの **Mode (order)** シークバーは既に読み込んだ結果を切り替える操作であり、
求めるモード数やソルバーの設定を変更しません。結果のモード数は実際の出力ファイルに従います。
