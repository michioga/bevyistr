# bevyistr-interaction

Support crate for [bevyistr](https://github.com/michioga/bevyistr), a viewport-first
FrontISTR finite-element pre/post processor built with Bevy.

This crate is released in lockstep with the bevyistr application. Its API is
still evolving. For the desktop application, install the `bevyistr` package.

The Rust library name remains `interaction`; the published package name is `bevyistr-interaction`.
